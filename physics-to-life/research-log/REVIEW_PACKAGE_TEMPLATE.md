# Review package — <milestone>

Prepared for an external reviewer (human or model) with no conversational memory.

1. **Objective** — the question this milestone answers, and the pre-registered criteria.
2. **Methodology** — system, ground truth, conditions, labels, metrics, seeds, compute.
3. **Key code paths** — files and functions a reviewer should read first.
4. **Figures** — numbered, with one-sentence claims each figure supports.
5. **Metrics** — tables with confidence intervals; where they are stored.
6. **Failure cases** — what went wrong, bugs found, results that were discarded and why.
7. **Interpretation** — verdicts on hypotheses; what is and is not supported.
8. **Threats to validity** — leakage, shift, confounding, circularity, gaming.
9. **Open questions**.
10. **Next proposed actions** — with the decision the owner is asked to make, if any.
